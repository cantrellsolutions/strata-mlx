# Legacy M5 Pro evidence, October 15, 2026

These files were generated by the preserved legacy-harness.py, not the cleaned experiment in bench/experiments. The source/runtime was pinned to 2842c51019604549329cc5d7bb9846ad8b04ff7d, MLX 0.32.3, float16 with TF32 environment unset. Hardware was one 20-core M5 Pro, 64 GiB. The exact original lab artifacts remain outside this contribution and were checksum-verified before packaging. configuration.json model paths were shortened to filenames for this package.

The cleaned experiment changes the protocol: actual machine memory, exclusive output ownership, explicit phase boundaries, finite checks, type-sensitive grading, and adaptive-policy reset by default. Its separate bounded Q2_0 GPU smoke is retained in ../e54-cleaned-smoke; do not attribute these legacy timings to the cleaned code. legacy-summary.py and comparison-summary.json preserve the original analysis. validated-summary.json was regenerated with the stricter analyzer and explicit 20 micro rounds, 3 answer rounds, windows 1/4/7/8 and these synthetic fixtures. It rejects missing/duplicate work and validates paired prompt identity/JSON types. Finite-logit and finish-cap metadata absent from the legacy run are explicitly marked unverified. Interpolated percentiles in the validated analysis differ from the old floor-index estimate.

Free-answer controls produced different token sequences despite identical settings. Adaptive draft policy persisted across legacy requests. Whole-answer sums are descriptive and cannot establish isolated kernel speed. The fixed-window fusion 6 versus 8 result remains a bounded one-prefix pilot. No chip-wide or cross-day confidence claim is made.

Pull request 11 delivered this folder as `bench/results/e46-m5pro`. It was renamed `e54-m5pro` at the merge, since this repository's e46 is another experiment; the files in it other than this README are byte for byte as delivered. The page is `docs/wiki/experiments/e54-shared-weight-controls.md`.
